Student: Ouyang Jie
Group: G11

Group members not stated at the start of the slides. Aden, Jie, Ariana, Jingtong, Azriel.

Gameplay reminds me of “He is Coming,” and is a static 2D board. This game is also rather implementable because it uses a lot of easy-to-design graphics, and the game does not seem too unrealistic to create. Also one of the few games to use horror, which makes it stand out from the other groups. The graphics also flow rather well and the overall mood of the game is clear.

Use of a pivot table and use of player_retention is something unique. I appreciate that the group tried to link the game to a business metric and not only talk about the game design. This group was also second in ranking for the voting for the section, so it is clear that classmates also found the concept interesting.

Weaknesses – linkage to current auditing standards such as COBIT framework is recommended. Could have expanded more on what player_retention was and how it affects gameplay, user behavior, and game improvement. The accounting/control connection is there but can be stated more clearly. Overall, a strong presentation and one of the better concepts.
