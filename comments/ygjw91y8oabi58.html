Khalid, Guy, Gabriela, Yeshi.

Concept of Budget Boss is rather stellar because there are a lot of boss tycoon plots popular today in the zeitgeist. The heir, grinder, and freelancer are archetypes offered, which fixes the game’s direction and gives different player identities. A dashboard is also provided, so the group did think about how the player would view financial information.

The only DA presented is game-profit by genre, which again makes the assumption that because that is a high level, therefore I must create a game in this segment. This is not a fully strong argument. More analysis would be useful, such as target users, education games, or budgeting behavior.

While the premise looks good, the gameplay seems simplistic as the user must balance budget, and unexpected cards appear. There are apps that do management for people, such as Rocket Money, so I am not sure how impactful this game is unless the group explains the learning value better. Group however, did heed my advice to make slides less corporate. Overall, good concept but gameplay can be expanded.
